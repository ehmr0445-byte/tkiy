# The King In Yellow (Minecraft 1.20.1 / Forge 47.3.0)

## Como compilar pelo GitHub
1. Crie um repositorio novo no GitHub (pode ser privado).
2. Envie TODOS os arquivos desta pasta (inclusive a pasta oculta `.github`).
3. Va na aba **Actions**. A compilacao inicia sozinha a cada envio.
4. Ao terminar (marca verde), abra a execucao e baixe **kingyellow-mod** em *Artifacts*.
5. Extraia o zip: o `.jar` e o mod.

## Como instalar no SKLauncher
1. Instale o Forge 1.20.1 (47.3.0 ou mais novo da serie 47) pelo SKLauncher.
2. Abra a pasta do jogo e coloque o `.jar` em `mods`.
3. Inicie o perfil do Forge 1.20.1.

## Teste da etapa 1
No modo criativo, procure a aba "The King In Yellow": deve haver o item "Pagina Amarela".
Se houver erro, envie o log da aba Actions (ou `logs/latest.log` do jogo).
